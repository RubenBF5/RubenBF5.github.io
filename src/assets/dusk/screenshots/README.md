Aquí están las capturas de Dusk usadas por la galería. También puedes agregar más en formato PNG, JPG, WebP o AVIF.

Las imágenes actuales son copias preparadas a partir de las capturas compartidas en el chat. Para conservar los píxeles originales, sustituye cada archivo por su captura fuente.

El nombre del archivo aparece como título. Usa prefijos numéricos para fijar el orden, por ejemplo:

- `01-peso-y-progreso.png`
- `02-buscar-alimento.png`
- `03-perfil.png`
- `04-nutricion.png`
- `05-carrera-y-actividad.png`

La galería detecta las imágenes automáticamente al compilar el sitio.
